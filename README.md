# Banco de Exámenes — AECCI

Repositorio de materiales académicos de la Escuela de Ciencias de la Computación e Informática (ECCI), UCR, administrado por la Asociación de Estudiantes de Computación e Informática (AECCI).

## Estructura del repositorio

Los archivos están organizados en 5 niveles jerárquicos, desde lo general (año de carrera) hasta lo específico (material de un semestre concreto).

```
.
├── Año_1
│   ├── Ciclo_1
│   │   ├── X_introduccion_a_la_computacion_CI0110
│   │   └── X_introduccion_a_la_matematica_para_computacion_MA0291
│   └── Ciclo_2
│       ├── X_calculo_para_computacion_i_MA0293
│       ├── X_estructuras_discretas_CI0111
│       └── X_programacion_i_CI0112
├── Año_2
│   ├── Ciclo_1
│   │   ├── X_algebra_lineal_para_computacion_MA0292
│   │   └── ... (otros cursos)
│   └── Ciclo_2
│       └── ... (cursos)
└── Año_3, Año_4, Optativas
    └── ... (estructura similar)
```

> Las carpetas prefijadas con `X_` son **placeholders temporales** sin contenido. Aparecen para mostrar la estructura completa del plan de estudios.

## Contribuir

### 01 · Agregar material

Creá un pull request en este repositorio respetando la estructura detallada arriba. Tus cambios serán revisados antes de publicarse.

**Flujo:** Fork del repo → Agregás el material → Abrís un Pull Request → Se publica

### 02 · Modificar o censurar

Si necesitás eliminar o censurar información personal en un documento existente, también podés usar el mismo flujo de pull request.

### 03 · Archivos grandes

Si un archivo es demasiado grande para añadirse a Git, contactá a un administrador directamente:

📧 [bancoexamenes.ucr@gmail.com](mailto:bancoexamenes.ucr@gmail.com)
